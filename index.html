Web Services Basics

How a website reaches you, and how calls and extra features work on the internet, explained in simple words.

Domain Name

The name of a website

Computers find websites using IP addresses, which are numbers like 203.0.113.10. A domain name is an easy name for that number, like a contact name saved in your phone.

https://www.example.com

https://
Protocol: the rules used to talk to the website.
www
Subdomain: a part of the site, like blog or shop.
example
The name you choose and register.
.com
Top-level domain: the type of site. Others are .org, .edu, .gov and .in.

How to get a domain name

  • Pick a short, easy name.
  • Check at a registrar whether it is free.
  • Pay a yearly fee to register it.
  • Connect it to your web hosting.

Domain Name · DNS

DNS: the phonebook of the internet

DNS (Domain Name System) changes a domain name into its IP address.

  1. You type www.example.com in the browser.
  2. The browser asks a DNS server: "What is the IP address of this name?"
  3. The DNS server replies with the IP address.
  4. The browser connects to that address and shows the website.

Remember

  • Domain name: easy for people.
  • IP address: used by computers.
  • DNS: connects the two.

Web Server

The computer that sends you the web page

A web server is a computer with special software that stores websites. When you ask for a page, it finds the page and sends it to you. It stays switched on all the time.

  1. Your browser (the client) sends a request for a page.
  2. The web server finds the page.
  3. The server sends the page back, and your browser shows it.
Apache

ClientYour browser, which asks for the page
HTTPThe rules for sending web pages

Web Hosting

Space on a server for your website

Web hosting is a service where a company gives you space on its web server to keep your website files, so people can open your site any time. The domain name is the address. Hosting is the plot of land where the site is built.

TypeWhat it meansCost
SharedMany websites share one server, like sharing a flat.Lowest
VPSShared machine, but you get your own private part.Medium
DedicatedOne whole server only for you, like owning a house.Highest
CloudMany connected servers. You pay only for what you use.Pay as you use

Small school or blog sites usually use shared hosting. Big websites use dedicated or cloud hosting.

VoIP

Calls over the internet

VoIP (Voice over Internet Protocol) lets you make voice and video calls using the internet instead of a phone line. WhatsApp calls, Skype and Google Meet are examples.

CallerReceiver
  1. Your voice is turned into digital data.
  2. The data is cut into small packets.
  3. The packets travel over the internet.
  4. The other phone joins the packets and plays your voice.

Advantages

  • Cheap or free calls, even to other countries.
  • Works anywhere there is internet.
  • Can also send video and messages.

Limits

  • Needs a good internet connection.
  • No internet or power means no call.
  • Voice may break if the network is slow.

Add-ons & Plug-ins

Extra features for your browser

An add-on or plug-in is a small program that you install to give your browser or software a new feature. You do not need to build anything from scratch.

Add-ons

  • Small tools that add features to the browser.
  • Examples: ad blocker, password manager, grammar checker.

Plug-ins

  • Help the browser show special content, like PDF files or videos.
  • Examples: PDF viewer, Java, Flash Player (now discontinued).

Use them safely

Trusted sourceInstall only from the official store.
Read reviewsCheck ratings before you install.
Remove extrasDelete the ones you do not use.
