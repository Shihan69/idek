Domain Name

The name people type instead of a number

A domain name is the readable address of a website. It points to a server's IP address, so visitors never need to remember digits like 203.0.113.10.

https://www.example.com

https://
Protocol the browser uses to talk to the server.
www
Subdomain. You can add as many as you like, such as blog or shop.
example
Second-level domain. This is the name you register and pay for.
.com
Top-level domain (TLD). Others include .org, .net and country codes like .in or .uk.

Getting one

  • Search for the name at an ICANN-accredited registrar to see if it is free.
  • Register it for 1 to 10 years, then renew before it expires or it can be lost.
  • Switch on WHOIS privacy so your contact details are not public.
  • Point it at your host by editing its DNS records.

Domain Name · DNS

How a name turns into an address

  1. The browser checks its own cache for www.example.com.
  2. If it is not cached, the browser asks a recursive resolver, such as your ISP's or a public one like 8.8.8.8.
  3. The resolver asks a root server, which points it to the servers for .com.
  4. The .com servers point to the domain's own name servers, listed in its NS records.
  5. Those name servers return the IP address. The resolver caches it for the record's TTL and passes it to the browser.

A and AAAA give the IPv4 and IPv6 address. CNAME makes an alias. MX routes email. TXT holds text such as email-sender rules. NS names the servers in charge. A change can take as long as the old TTL to reach everyone.

Web Server

The program that answers every page request

A web server is software on a machine that is always online. It receives HTTP requests and sends back pages, images, or the output of an application.

# browser asksGET /index.html HTTP/1.1Host: www.example.com # server answersHTTP/1.1 200 OKContent-Type: text/html <!doctype html> …

Static sites send files as they are. Dynamic sites pass the request to PHP, Node.js or Python, which builds the page first.

Apache
Open-source and long established, configured per folder with .htaccess files.
Nginx
Event-driven. Common for static files and as a reverse proxy in front of apps.
IIS
Microsoft's server for Windows Server and ASP.NET sites.
LiteSpeed
Works with Apache settings and is common on shared hosting plans.

VoIP

Phone calls over the internet

Voice over IP turns speech into data packets and sends them over the same networks that carry web pages, instead of over traditional phone lines.

CallerCallee
  1. The microphone captures your voice.
  2. A codec digitizes and compresses it.
  3. Packets cross the network. SIP sets up and ends the call, and RTP carries the audio.
  4. The other device puts the packets back in order and plays the sound.
SIP port5060, or 5061 with TLS
CodecsG.711 64 kbps · G.729 8 kbps · Opus adaptive
Bandwidthabout 80 to 100 kbps per G.711 call
Delaykeep one-way under 150 ms
Addresssip:alice@example.com

SIP addresses reuse the domain name system, so the domain from slide 2 can also route calls.

Ways to use it

  • A softphone app on a laptop or mobile
  • An IP desk phone
  • An adapter that connects an ordinary phone
  • A hosted cloud phone system with voicemail-to-email and an auto attendant

Limits to plan for

  • No internet or no power means no calls, so keep a backup line.
  • Jitter and packet loss make audio choppy.
  • Ask your provider how emergency calls find your location.

Add-ons & Plug-ins

Extra features without rebuilding the software

An add-on extends a program that already exists. The words add-on, plug-in and extension overlap, and the one used usually depends on the host program.

In the browser

  • Called extensions in Chrome and Edge, add-ons in Firefox.
  • Common examples are ad blockers, password managers and grammar checkers.
  • Each one lists the permissions it asks for before you install it.
  • Old browser plug-ins like Flash are gone. Adobe ended Flash support on 31 December 2020.

On a website

  • Content management systems such as WordPress add features through plug-ins.
  • Common jobs are SEO, contact forms, caching, backups and online shops like WooCommerce.
  • Themes change how a site looks. Plug-ins change what it does.

Use them safely

Official sourcesInstall only from the browser's store or the CMS directory.
Check the ageLook at the last update date and the reviews.
Keep it leanDelete what you do not use. Each plug-in adds code to load.
Back up firstTake a backup before a large update.
